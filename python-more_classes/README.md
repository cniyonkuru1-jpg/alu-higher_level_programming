# python-more_classes

This project explores Object-Oriented Programming in Python 3 through a
progressively enhanced `Rectangle` class: private attributes, properties,
`__str__`/`__repr__`, class attributes, static methods, and class methods.

## Files

| File | Description |
| --- | --- |
| `0-rectangle.py` | An empty `Rectangle` class. |
| `1-rectangle.py` | `Rectangle` with private `width`/`height` properties. |
| `2-rectangle.py` | Adds `area()` and `perimeter()`. |
| `3-rectangle.py` | Adds `__str__` for a printable representation. |
| `4-rectangle.py` | Adds `__repr__` for `eval()`-able reconstruction. |
| `5-rectangle.py` | Adds `__del__` to announce instance deletion. |
| `6-rectangle.py` | Adds `number_of_instances` class attribute. |
| `7-rectangle.py` | Adds a customizable `print_symbol` class attribute. |
| `8-rectangle.py` | Adds the static method `bigger_or_equal`. |
| `9-rectangle.py` | Adds the class method `square`. |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- No imports allowed
- All files start with `#!/usr/bin/python3` and end with a newline
