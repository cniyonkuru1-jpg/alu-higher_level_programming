# python-network_0

Bash scripts that use `curl` to explore HTTP requests and responses:
status codes, headers, HTTP methods, and request bodies.

## Learning Objectives

- What is a URL and how it's structured (protocol, domain, path, query string)
- What is an HTTP request/response and its main components
- What are HTTP headers, and how they're used
- What are common HTTP methods (GET, POST, DELETE, PUT, OPTIONS)
- How to use `curl` to perform HTTP requests

## Files

| File | Description |
| --- | --- |
| `0-body_size.sh` | Displays the size (in bytes) of the response body |
| `1-body.sh` | Displays the response body only for a `200` status code |
| `2-delete.sh` | Sends a `DELETE` request and displays the response body |
| `3-methods.sh` | Displays all HTTP methods a server accepts |
| `4-header.sh` | Sends a `GET` request with a custom header |
| `5-post_params.sh` | Sends a `POST` request with `email` and `subject` params |
